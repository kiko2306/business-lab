🔕 Notificações de descida de preço

Aviso quando um preço descer 10% ou mais.

Problemas ao ativar as notificações?
  1. Toque no ícone de cadeado/informação junto ao endereço do site, no navegador, e reponha as permissões deste site.
  2. No telemóvel, confirme que o navegador tem permissão para enviar notificações: Definições do sistema → Aplicações → (o seu navegador, ex. Chrome) → Notificações → ativar.
  3. Feche e reabra a página, inicie sessão novamente e tente ativar de novo.
  4. Se continuar a falhar, limpe os dados do navegador para este site: Definições do sistema → Aplicações → (o navegador) → Armazenamento → Limpar armazenamento — depois repita os passos acima.
